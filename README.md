# বাজার দর (BazarDor)

BazarDor is a web application that allows users to explore products and check their prices in one place. It provides a simple browsing experience along with secure authentication and user profile management.

## 🛠️ Technologies Used

- **Next.js 16** – React framework
- **React 19** – UI development
- **MongoDB** – Database
- **Better Auth** – Authentication
- **HeroUI** – UI components
- **Tailwind CSS** – Styling
- **Lucide React** – Icons
- **React Icons** – Additional icons
- **React Hot Toast** – Notifications
- **React Marquee Text** – Scrolling text

## ✨ Key Features

1. **User Authentication** – Sign up and sign in using email and password or Google.
4. **Profile Management** – View and update user name.
5. **Responsive UI** – Clean and user-friendly interface for a smooth browsing experience.
